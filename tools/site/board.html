OraclePet / USB / __BOARD__

Flash the __BOARD__ over USB

  1. Plug the board in with a USB data cable.
  2. Press Install and pick its serial port (often usbmodem… or USB JTAG/serial).
  3. Wait for the write to finish, then the board restarts into the pet.
This browser has no Web Serial. Use Chrome or Edge on desktop.

Writes bootloader, partition table, OTA data, the app (default character: siamese) and the 3 MB character storage. Later updates can go over Bluetooth from the BLE tool.
