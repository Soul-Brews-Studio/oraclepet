OraclePet

An open desk pet for ESP32-S3 boards. Install it over USB once, then update firmware, characters and apps over Bluetooth, all from this page.

1. First install, over USB

  • Guition JC3248W5353.5″ 320×480 · pick a character, live preview
  • WT32-SC01 Plus3.5″ 480×320
  • ESP32-S3 2.8″240×320, ILI9341 + speaker

2. Updates, over Bluetooth

  • BLE toolfirmware OTA, character packs, WebAssembly apps, speaker and mic test

For a firmware update over Bluetooth, download your board's app image from firmware/ (jc3248/app-<pack>.bin, sc01/app-siamese.bin, lcd28/app-siamese.bin), then choose it in the BLE tool. Checksums: SHA256SUMS.

Before you start

  • Chrome or Edge on desktop, or Chrome on Android. Safari, Firefox and iOS cannot do Web Serial or Web Bluetooth.
  • A pet talks to one host at a time. Quit the OraclePet Mac app before using the BLE tool.
  • The Bluetooth update service has no pairing: anyone in range can send the pet an image while it advertises. The pet checks size, CRC and board name, and rolls back an image that fails to boot.
